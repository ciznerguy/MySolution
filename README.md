# הרצה ראשונה של הפרויקט

מסמך זה מיועד לתלמיד שמוריד (`git clone`) את הפרויקט למחשב חדש, ומסביר בדיוק מה צריך להכין ומה יקרה בהרצה הראשונה.

## לפני שמתחילים - מה צריך להיות מותקן

1. **.NET 10 SDK**
2. **שרת MySQL** מותקן ורץ על המחשב שלך (למשל MySQL Server + MySQL Workbench, או XAMPP), עם שם משתמש וסיסמה שאתה יודע (ברוב ההתקנות: `root` + הסיסמה שקבעת בהתקנה).
3. **Visual Studio 2022+** (או `dotnet` CLI בלבד).

**חשוב:** לא צריך ליצור מראש את בסיס הנתונים או את הטבלאות - הקוד עושה את זה בעצמו בהרצה הראשונה (ראה בהמשך).

## שלב 1: שכפול הפרויקט

```bash
git clone <כתובת-הריפו>
```

לא יגיע איתו שום קובץ סיסמאות - זה מכוון. פרטי ההתחברות למסד הנתונים **לא** נשמרים בגיט מטעמי אבטחה (ראו [CLAUDE.md](CLAUDE.md#dal--connection-string-handling)).

## שלב 2: הרצת ה-API בפעם הראשונה - כאן מזינים את הפרטים

יש להריץ קודם את **MyProject.API** (לא את View):

```bash
dotnet run --project MyProject.API
```

(או ב-Visual Studio: קליק ימני על MyProject.API → Set as Startup Project → F5)

מכיוון שזו הרצה ראשונה על המחשב שלך, לא קיימת עדיין אצלך שום מחרוזת חיבור שמורה. הקוד יזהה זאת ויציג לך **בחלון הקונסולה** (לא בדפדפן) שאלות **באנגלית** (בכוונה - קונסולת Windows לא מציגה עברית כראוי):

```
=== First run: no database connection string found ===
Enter your local MySQL connection details (press Enter to accept the default in brackets):
Server [localhost]:
Port [3306]:
Database name [online_store]:
Username [root]:
Password:
```

**מה להזין בכל שדה:**

| שדה | מה זה | מה להקליד |
|---|---|---|
| Server | הכתובת של שרת ה-MySQL שלך | ברוב המקרים `localhost` - פשוט לחץ Enter לברירת המחדל |
| Port | הפורט שה-MySQL מאזין עליו | ברירת המחדל `3306` בדרך כלל נכונה - Enter |
| Database name | השם שהקוד ישתמש בו (ייווצר אוטומטית אם לא קיים) | Enter לברירת המחדל `online_store`, אלא אם יש לך סיבה לשם אחר |
| Username | משתמש ה-MySQL שלך | לרוב `root` - Enter, אלא אם יצרת משתמש ייעודי |
| Password | **הסיסמה של משתמש ה-MySQL הזה במחשב שלך** (לא סיסמה מהריפו - אין כזו!) | הסיסמה שקבעת בעצמך כשהתקנת את MySQL |

לאחר מכן הקוד:
1. שומר את הפרטים שהזנת בקובץ **User Secrets** במחשב שלך בלבד - מחוץ לתיקיית הפרויקט לגמרי (`%APPDATA%\Microsoft\UserSecrets\...\secrets.json`), כך שהם **לעולם לא** יעלו לגיט.
2. יוצר אוטומטית את בסיס הנתונים אם אינו קיים.
3. יוצר את הטבלאות `PERSON`, `PRODUCTS`, `PURCHASES` אם אינן קיימות.
4. אם הטבלאות ריקות - מזין נתוני דוגמה: 4 משתמשים, 4 מוצרים ו-3 הזמנות.

**בהרצות הבאות** (מכאן והלאה) - הקוד כבר לא ישאל שוב. הוא ימצא את הפרטים השמורים וידלג ישר להרצה.

## שלב 3: הרצת ממשק המשתמש (View)

בטרמינל **נוסף** (השאר את ה-API רץ ברקע):

```bash
dotnet run --project View
```

ופתח דפדפן בכתובת `http://localhost:5144`.

**שים לב:** שני הפרויקטים (`MyProject.API` ו-`View`) חייבים לרוץ **בו-זמנית** - ה-View מדבר עם ה-API דרך HTTP (לא הפניית פרויקט), כמו שמוסבר ב-[CLAUDE.md](CLAUDE.md).

## אם משהו משתבש

- **שגיאת חיבור למסד נתונים** - ודא ששרת ה-MySQL שלך פועל בפועל, ושהפרטים שהזנת (שם משתמש/סיסמה) נכונים.
- **רוצה להזין פרטים אחרים** - מחק את הקובץ ב-`%APPDATA%\Microsoft\UserSecrets\<UserSecretsId>\secrets.json` (ה-GUID מופיע ב-`MyProject.API.csproj` תחת `<UserSecretsId>`), או פשוט ערוך אותו ידנית / דרך Visual Studio (קליק ימני על הפרויקט → Manage User Secrets).
